# Проверка перечня нарушений оформления

Проверено для варианта 8, «Практика 2 варианты.pdf», 28.09.2026.
Проверяется содержимое Git: зависимости `node_modules`, временный SDK,
архивы сравнения и изображения в `output` не входят в репозиторий.
Настройки путей редактора в код и историю не добавлялись.

Каждый из пяти этапов имеет отдельный Conventional/Scoped Commit с
детальным сообщением. Каждое состояние прошло свои тесты и проверку
оформления. Для этапов 1-5 пройдено соответственно 3, 8, 12, 14, 17 тестов.
После уточнения подсчета сложности исправлено также состояние этапа 2;
этапы 3 и 4 повторно проверены с этой реализацией.

Максимумы итоговых файлов: 165 строк в файле, 80 символов в строке Python,
28 строк в функции, 3 аргумента, сложность 10. В подсчете сложности
учтены условия, циклы, обработчики ошибок, логические операции,
тернарные выражения и условия в генераторах/включениях.
