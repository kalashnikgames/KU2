# Практическая работа 2, вариант 8

Инструмент анализа и визуализации зависимостей NuGet на Python.
Этот коммит содержит этап 1: CLI, TOML-конфигурацию, проверку всех
параметров и вывод значений в формате `ключ=значение`.

## Запуск и сборка

Python 3.11 или новее. Сборка и дополнительные пакеты пока не нужны.
Из корня репозитория выполните:

```text
run.bat examples\test.toml
python -B -m src.cli examples/test.toml
python -B -m unittest discover -s tests -v
```

## Настройки TOML

| Поле | Назначение |
| --- | --- |
| `package` | Имя пакета; в тестовом режиме только большие латинские буквы. |
| `repository` | URL NuGet V3 или путь к JSON-файлу тестового репозитория. |
| `test_mode` | `true` для файла, `false` для настоящего NuGet. |
| `version` | Конкретная версия пакета, например `8.0.0`. |
| `output` | Имя PNG-файла, относительный путь от TOML. |
| `filter` | Подстрока исключаемых имен; пустая строка отключает фильтр. |
| `framework` | Дополнительно: `net8.0` по умолчанию или `net9.0`. |

Отсутствующие и неизвестные поля, неверные типы, пути, URL и версии
вызывают понятное сообщение и код завершения 1. Все пути в файле
разрешаются от его каталога. Исходные файлы находятся в `src`, проверки
в `tests`, примеры в `examples`.
